# Design style for Ling cards and figures

Taken from Daniel's Ling-3.2-air pre-registration page (25 Nov 2026), which echoes inclusionAI's visual identity.

- Type: Red Hat Display 700 for titles and figure headings, Red Hat Text 400/500 for body and labels (matplotlib: install-free fallback DejaVu Sans if the fonts are not available; say so).
- Title band: oxford blue gradient `linear-gradient(135deg, #081a52 0%, #16257a 55%, #33237e 100%)`, white text, meta text `#c9d3ef`, links `#8fe0ff`.
- inclusionAI accent gradient: `#2ec5ff` → `#4a63ff` (55%) → `#8b5cf6`. Used for gated-MLA layers and the main accent ("ours").
- KDA layers: pale sky `#cdeeff`. Dense FFN layers: `#7f93c9`. Router/borders: `#8fa3d6`.
- Warm accent (few uses: gates, corrections, highlights): `#f6d77a` → `#ef9a6a`; warm text `#c4521f` (light) / `#f6a56e` (dark).
- Light theme: background `#ffffff`, ink `#0b1020`, muted `#4a5470`, rules `#d9deea`, panels `#f1f4ff`. Dark: background `#05132e`, ink `#e8ecf7`, muted `#a5afc9`, rules `#22305a`, panels `#0e1d55`.
- Main blue `#4a63ff` (dark-mode variant `#9db4ff`), deep `#3346e0`, oxford `#0b1d5c`.
- Voice: calm and exact, a lab poster. Claim first, then one full-width diagram, then ruled tables.
- Signature figure: the layer stack, one bar per layer, KDA pale sky, gated MLA in the gradient, dense layers slate; brackets under groups; a byte-share bar below.
